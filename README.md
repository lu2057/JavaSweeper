# JavaSweeper
JavaSweeper is a sple port of the classic minesweeper made entirely in Java!
It uses the Swift GUI to display the window anche to manage any visuals.
With all the game logic and GUI code written in a single class (probably a bad thing to do), it gives the player the choice for number of rows, columns and mines.
The project also has a .deb file and a .jar archive!

I think the code is sufficiently documented with comments througout the file.

Some game logic and GUI code was written with the help of Copilot, only in cases i had problems with fuctionality (as this is my first game made in Java)
